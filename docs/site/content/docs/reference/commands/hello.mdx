The example command the template ships. Delete it once you have a real one —
it exists to show the shape, not to be useful.

## What it does

Prints a greeting to stdout. The implementation lives in
`src/precommit_hooks/commands/hello.py` and **returns** its string rather than
printing it; `cli.py` does the printing. That split is deliberate — it keeps
the behaviour testable without capturing stdout.

## Output

One line on stdout:

```console
$ precommit-hooks hello
Hello, world!
```

## Flags

| Flag | Type | Default | Effect |
| --- | --- | --- | --- |
| `NAME` / `--name` | string | `world` | Who to greet. Must contain at least one non-space character. |
| `--shout` / `--no-shout` | bool | `False` | Uppercase the whole greeting. |

`NAME` is positional-or-named: `hello Robin` and `hello --name Robin` are
equivalent.

## Exit codes

| Code | Meaning |
| --- | --- |
| `0` | Greeting printed. |
| `1` | `NAME` was empty or whitespace only. The message goes to stderr as `precommit-hooks: name must not be empty`, with no traceback. |

The clean exit-1 path is `main()` catching `ValueError` in
`src/precommit_hooks/cli.py`. Raise `ValueError` from a command to get the same
treatment.

## Examples

```console
$ precommit-hooks hello
Hello, world!

$ precommit-hooks hello Robin
Hello, Robin!

$ precommit-hooks hello Robin --shout
HELLO, ROBIN!

$ precommit-hooks hello "   "
precommit-hooks: name must not be empty
$ echo $?
1
```
